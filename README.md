**An OCR Translator.**

**How it works:**
The file creates a transparent window that goes **OVER** something you want to translate, it then captures what's beneath the 
window and translates it using the deep_translator library.

Note: if you're gonna use this project, please make sure to change the path for the photo and the text file to your own paths.

**Dependancies:**
- *PyAutoGui*
  -pip install PyAutoGui
- *easyocr*
  -pip install easyocr
- *langdetect*
  -pip install langdetect
- *deep_translator*
  -pip install deep_translator

This project is still in Alpha. Don't expect it to be completed anytime soon.
